# 双边网格颜色数据
source 为线性RGB float32 [H,W,3]，guidance 为 [H,W] 且有效值位于 [0,1]，valid 为真实图像有效位；未到达由 tile 完整性表示，不能等同 valid=false。grid:[Gy,Gx,Gz,3,4]，每个网格点为三行仿射系数，最后一列为偏置。像素中心映射 u=(x+0.5)*Gx/W-0.5、v=(y+0.5)*Gy/H-0.5、z=guidance*(Gz-1)，端外按边界复制；在三维网格三线性插值得到系数，乘 [R,G,B,1] 形成输出，不额外截断颜色。Gz>=2。只有真实有效像素进入损失。
锚点按稳定 anchor_id 与全图像素坐标定义，target_rgb 和每通道 tolerance 为闭区间约束；grid 每元素在 [-coefficient_bound,coefficient_bound]。更新接口接收候选 grid 和可选可训练目标，产品必须判定候选是否满足全部有效锚点；当编辑者要求调整以满足锚点时，需在幅度限内求使与候选 grid 的平方距离最小的可行网格，无法满足则拒绝本次编辑，不能覆写像素。锚点所在片未到达时等待事实，坐标越界或 valid=false 则该锚点无效并拒绝编辑，不能忽略。这里规定优化目标与约束，不规定求解方案。
同一图像一次领取会话固定 source/guidance revision 和 grid_version；新会话可使用更新网格，已开始会话保持一致。训练梯度返回 source、guidance、grid，guidance 恰落整数切片边界采用右侧导数，最右端按左侧，复制边界外对坐标导数为零。训练目标可由多个消费者提供梯度，按目标身份求和，无隐式平均。候选更新的约束选择为离散操作，不对此选择本身求导。
支持 H,W<=2048，grid <=16*16*8，实际活跃锚点<=64；分片至少16*16，临时工作区16 MiB，不含调用方原图/指导/网格和最终输出梯度，整图插值系数或 [H,W,8,...] 支撑表计入，不能以输出名义保存。float32 数值 atol=3e-5、rtol=5e-4；梯度 atol=3e-4、rtol=2e-3；锚点约束判定容差1e-6。
